15 October 2026. These new pure reducers implement the assigned prompt-size PS and start-state CP calculations. They import no producer module and read no original outcomes. Only source files, frozen designs and Inference's metadata-only readback have been inspected. Task23 has execution priority. There is no admitted Task25 target run or manufactured execution.

`prefix.py` takes explicit model/prefix coarse and fine row lists, with optional original-attempt provenance. It retains every raw row, source-literal class, finite/period qualification, per-stage coverage, C1/C2/M and all four-decimal display coordinates alongside the original coordinates. Both hidden and visible chaos count as chaotic; period>0 has precedence and each saved exponent must exceed0.001. A nonfinite exponent can satisfy a literal comparison (for example positive infinity), but is independently marked unqualified. No classifier is silently repaired.

All20 model-prefix combinations remain in the table. Development prefixes0/1 cannot affect held-out2–9. The frozen PS1 rule keeps its strict decline and forbidden increase greater than2; it remains undetermined when missing pairs could still violate the condition. PS2 can already hold after six observed successes even with other pairs missing. PS3 is descriptive. Empty or malformed stages retain a source-refusal disposition; absent stages remain missing. Incomplete but interpretable stages retain their literal calculation and explicit48/24 coverage failure. These are evidence qualifications, not replacement scientific thresholds.

The adaptive fine selector is the first `argmax(diff(H))` in original row order. It uses raw entropy increments, not slopes, and widens to indices max(i−1,0) and min(i+2,n−1). Every increment, maximizing tie, selected endpoint and exact24-point `linspace` association is retained. No sorting, interpolation, favorable transition selection or silent NaN removal occurs. Nonfinite selection inputs and nonincreasing axes are explicit. Stage2 selection was part of the frozen design, so it is not a second independent fixed-grid replicate.

`start.py` uses the exact14 dense-model list and the literal frozen three-decimal outcome values in the original CP design. Saved full-precision scalar breadth at prefix0, median breadth over ten prefixes, log network gain, gain maximum and parameter count are the scored predictors. The primary correlations do not use rounded profiles and never replace frozen outcomes with later expanded sweeps. Current scale values enter only the separately named sensitivity calculation. The coordinator must associate the current-scale projection by exact family/model keys; a missing or source-refusing scale row cannot be substituted from another dataset. Every model remains visible, including missing models and present records that the original scorer would refuse. A present source-refusing model prevents the global literal CP score rather than being silently dropped.

Spearman uses independent stable sorting, exact represented-value ties, average ranks and the Pearson correlation of ranks. It records all inputs, ranks, permutations and ties. The reported p-value uses the original scorer's conventional two-sided Student-t approximation with n−2 degrees of freedom (`scipy.special.stdtr` evaluates that distribution only); it is neither an exact permutation p-value nor a scientific decision gate. All rows are retained; nonfinite or constant vectors are undefined. CP1/2 use rho≥0.5 only. CP profiles were rounded to five decimals by the producer, whereas breadth, crossing width, entropy atT=1, network scalar and one-step maximum were computed before rounding. The compatibility routine therefore reports direct rounded-profile reductions and every discrepancy, then uses outward rounding cells ±0.5e−5 plus an explicit binary64 rounding allowance. It records all601 entropy points/weights, all81 readout points, strict-threshold ambiguities, all possible first-crossing indices, discrete saved-width matches and candidate-width ranges. Breadth bounds also include the declared floating-sum allowance. These are conditional saved-number compatibility intervals, not certified enclosures of model evaluation. A compatible interval cannot reconstruct lost digits or prove native precision. Nonfinite profiles are retained as unavailable rather than filled or omitted.

The gain check retains the first maximum of the rounded profile and every candidate argmax whose rounding cell could contain the true maximum. Saved argmax and maximum are checked against that set/interval; no single reconstructed peak is substituted. The network range check concerns only saved scalar ordering. Individual directional gains, logits, hidden vectors, native computations and their precision were not saved in this interface and cannot be reconstructed here. In particular the source proxy is `log(median(g_net directions)) + log(median(g_read directions))` at each temperature. It is not a median of paired total gains or a median of log gains.
