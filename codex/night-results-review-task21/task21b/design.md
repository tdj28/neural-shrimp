# Task21b prospective saved-spectrum arithmetic

This preparation is independent arithmetic on saved finite Lyapunov estimates. It imports no producer code, runs no model and reads no target spectrum. Expected KY1/KY2 cells, dimensions, estimator contracts, source identities and original completion status remain unset until Inference supplies the pinned source/card/input packet.

Every cell will retain its original input order, exact saved numeric spellings, source/attempt identifiers and all failures. Sorting is descending and stable, with the permutation saved. Cumulative sums and ratios use exact rationals of the saved decimal inputs; the eventual adapter will also retain the represented binary64 comparison where the original producer formula calls for one. No near-zero cutoff or epsilon denominator is introduced.

Let j be the largest retained index with a nonnegative cumulative sum, using j=0 if the leading value is negative. If the next cumulative sum is negative, the finite estimated dimension is j+S_j/|lambda_(j+1)|. This can be evaluated from a leading truncated spectrum when the crossing lies within the retained values. It is still a calculation from finite estimated exponents, not an exact attractor dimension. A source/card assertion that the retained values are the leading estimates is required before assigning that interpretation; arbitrary selected exponents do not establish it.

If all retained cumulative sums remain nonnegative, a truncated spectrum yields only D_KY at least the number retained under that same leading-spectrum assumption; the omitted tail remains indeterminate. If the full ambient spectrum is explicitly available, the usual finite-spectrum convention gives the ambient dimension. Strictly negative leading exponent yields zero; leading zeros followed by negative values give the corresponding neutral count. An all-zero truncated spectrum remains tail-indeterminate. The maximal-j rule prevents choosing a zero next denominator, and the implementation still explicitly refuses any zero-denominator case rather than inserting a floor.

Nonfinite, empty or inconsistent spectra remain explicit invalid rows. They are never discarded from the cell ledger. Range summaries include only supported point estimates, retain the original indices attaining each exact extremum, and display endpoints rounded outward from those actual extrema. Bound-only and indeterminate cells are listed separately; lower bounds are not mixed into a point-estimate range.

Ten tiny controls cover ordering, crossing arithmetic, all-negative and zero cases, truncated tails, absent leading-spectrum authority, nonfinite inputs, scale invariance, exact-zero sums and raw-derived outward ranges. No target test or timing run is proposed. A concrete bounded driver/card follows only after source and input admission; Inference owns all launch, lifecycle and Git actions.
