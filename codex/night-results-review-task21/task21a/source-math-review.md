**Map and derivative contract.** `llm_feigenbaum.py` 649–667 constructs `SoftLoop` with float64 requested, the selected vector and the given physical alpha; temperature is `10**log_temperature`. `SoftLoop` 37–64 fixes the prompt/window/embedding and 68–119 builds the prefix using the same steering. `SoftOrbit` 394–414 retains and repeats that prefix, while 416–455 implements the full-vocabulary softmax embedding map and its forward-mode directional derivative, including the shifted window. `llm_feigenbaum.chain` 72–78 applies these Jacobian actions in forward time along the evolving orbit, so the product is the derivative of the period-p map, not an arbitrary ordering of per-step matrices.

**Orbit and eigenvalue gates.** `newton` (81–99) is a low-rank quasi-Newton method, but it always tests the complete floating-point return residual. With orthonormal Q, W=MQ and a solving `(QᵀW−I)a=−Qᵀr`, its update is algebraically `Wa+r`; this solves the Newton equation for the approximation `M̂=WQᵀ`. The printed explanation that the neglected operator has the size of the next multiplier (lines 8–9) is not generally an operator-norm bound for a nonnormal matrix. A small next Ritz value supports the numerical approximation, not that theorem.

`tol_for` (48–52) uses `max(tol, 1e−13*p)`. `evaluate` (173–197) refuses a return residual at or above that tolerance and a detected collapse onto the half-period parent; complex critical values near −1 are refused. The start has a finite detected-period check (688–692), while later doubled levels specifically test the half-period separation. This is evidence for the stated numerical branch, not a rigorous all-divisor primitive-orbit certificate.

`ritz` (102–121) computes values and vectors in the retained subspace, sorted by modulus, and attempts to reduce watched residuals through repeated subspace iteration. At its iteration cap it returns the values even if the requested internal residual tolerance was not reached. The final locator then checks the critical residual against 1e−6 and `next_modulus<1` (238–241). `next_modulus` is the largest of the **other computed Ritz values** (148–151); it is not an independently enclosed bound on every unrepresented eigenvalue. The accepted finite report should retain the actual critical residual, observed next value, subspace dimension and return-residual history. It need not impose an unrequested dense eigensolve.

**What the explicit acceptance argument does.** Commit `44b22d3b43ac661df3a609abbeb49a86b3b1e3a2` changes the old fixed condition `abs(best.g)>1e−6` to `abs(best.g)>g_accept`, exposes the parameter on the cascade CLI and threads it through the caller. Its default stays 1e−6. It also exposes the already-existing `lam_rel_tol` value; the default stays 1e−13. The source change does not alter the ratio formula or compute a noise estimate.

The locator starts from opposite signs (205–208), uses Illinois interpolation (214–234), and stops when the bracket width is small enough **or** the best residual reaches `g_tol` (212–213). It finally checks the best single evaluation’s `|mu+1|`, imaginary part, critical Ritz residual and other computed Ritz moduli (238–241). It does **not** check an empirical scatter statistic, a regression residual, or `max(g)−min(g)`. Therefore the 06:27 FBD2 card statement “If the scatter ... exceeds 3e−4, the locator refuses” does not follow from this code. A run with wide scatter can pass if its best single residual passes. The narrow remedy is to correct that statement or explicitly score the retained scatter separately; this review does not request a new model run.

There is also no validation that `g_accept` is finite and positive at 633–636. That is a robustness cleanup, not evidence of a problem for an actual finite positive value such as 3e−4. It must not be used to retroactively add a new scientific success condition to the frozen finite run.

For a local model `g(alpha)≈m(alpha−alpha*)+error`, scatter divided by `|m|` is a sensible scale for numerical parameter sensitivity. Ordinary least-squares standard errors additionally assume a noise model; repeated deterministic floating-point evaluations along correlated warm starts are not independent random observations of a population. Neither that standard error nor a span of sampled alpha values is automatically a rigorous root enclosure. No source-enforced bound on the true evaluation error or on derivative variation is supplied here.
