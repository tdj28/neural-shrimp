## What the saved BZ/BP audit should establish

**BZ: preserve the matched-cell design and its actual uncertainty unit.** The frozen source selects nearest-temperature rows from two maps, then a chaotic/periodic alpha pair with minimum separation at most 0.001. Literal labels use exponent >0.05 with period 0, versus a detected period with exponent <−0.05; ties follow source iteration order. It also creates an unsteered control for each pair. Recompute the selected-coordinate association only if those original map/selection records are admitted; otherwise inherit the saved selection explicitly. A matched temperature and a small alpha gap do not randomize regime or eliminate direct steering effects.

For every original cell and task, retain all allocated item/sample keys, duplicates, missing cells, saved correctness, entropy and length; check saved group means and every complete chaotic-minus-periodic pair, with unsteered baseline separately. The source bootstrap unit is the **pair**, not each generated answer. Its task order is arithmetic, NQ, MBPP; metric order is accuracy, entropy, length; one seed-20261015 generator is consumed across all 10,000-resample calculations. The exact two-sided sign test uses only nonzero pair differences, returning one for an all-zero set. Report this literal reproduction separately from its inferential limits: shared task items and nearby/repeated cells do not become independent random draws merely because the bootstrap samples pair rows.

Arithmetic uses the first signed integer after deleting commas; NQ uses the exact case/punctuation/article normalization and gold-substring rule. Saved BZ replies are truncated to 400 characters, and BP replies to 200. Re-scoring available text can check saved text and flags, but truncated records cannot always reproduce the full original scoring input. MBPP correctness depends on an original code-test subprocess; this saved-data audit should authenticate its recorded flags/receipts and limitations, **not execute generated programs**. Retain the reported BZ floor as an observed limitation, not evidence of no possible regime effect.

**BP: preserve every original model, temperature, task and prompt.** Expected allocation must come from original cards and task files, not from surviving rows. The reviewed current contract uses three temperatures, per-prompt finite loop labels, a greedy response, and ten sampled answers. Preserve source-specific deviations, original failures, chunks and RNG changes. Join by literal prompt/task/model/condition/temperature identity; never let dictionary overwrites silently choose duplicate labels or generations. Keep every label and missing sampled row in a coverage ledger. The saved label records omit `lead_period` in the reviewed source, so their hidden-versus-visible subclass cannot be independently reconstructed from these fields alone; retain that inherited component. The chaotic union and detected-period precedence can be checked to the extent the original fields permit.

The original analyzer reports chaotic-minus-periodic prompt accuracy for all prompts and greedy-correct prompts, separately at each temperature. Its resampling unit is a prompt accuracy, not ten independent answers. It uses one seed-20261015 generator, in temperature then subset order, for 10,000 raw Monte Carlo exceedance fractions with inclusive absolute comparison. Reproduce that convention if the original version matches; record exceedance counts and do not interpret a zero fraction as an exact zero probability. Show all models/temperatures/subsets, with no post-hoc favorable selection or pooled model contrast.

To assess “mostly through task mix,” report task-by-label counts and task-specific differences first. A separately declared common-weight standardization can describe the part of the aggregate contrast associated with observed task composition, using only shared-support strata and explicit fixed weights; it is not a causal decomposition. Preserve strata lacking either label instead of extrapolating silently. The historical −4 to −5 percentage-point regression is not implemented by the reviewed `behavior_prompts.analyze`. It needs its exact original row construction/formula/inline source or a disclosed independent reimplementation before claiming replication. Generation entropy is measured during sampling, so adjustment for it is post-outcome-associated adjustment, not a pre-sampling confounder control. Greedy correctness uses gold labels. Neither adjustment identifies an interval between the raw and adjusted values within which the “true effect” must lie.

## Proposed future-fresh BP outline — not yet frozen

**Question and population.** Estimate whether a finite soft-loop regime label adds an adjusted association with ordinary-answer accuracy and held-out predictive information in one preselected arithmetic population. This is a benchmark diagnostic question. It is not a causal effect of chaos, a test of shrimp-specific benefit, or an identification of the mechanism linking the soft loop to ordinary decoding.

Before a freeze, choose one exact model revision, one temperature, one arithmetic family/template and a fixed prompt count/sample count. Using the old model and temperature is a transparent continuity choice, not independent hypothesis discovery. Specify the new prompt generator and arithmetic-equivalence key, then exclude every previously generated or inspected BP/BPC/BPCS/BZ question and equivalent commuted/rephrased version from the fresh cohort. The existing two-digit product universe is small; reusing a different spelling or swapped operands does not establish freshness. A larger unseen arithmetic domain is an option but changes the target population and must be named as such. The final cohort, exclusion inventory and unseen-status declaration must be fixed before new labels or answers are inspected. No exact N, power guarantee, equivalence margin or new threshold is invented in this outline.

**Ordering and measurement.** Freeze the exact prompt list, partition, scoring, source and analysis before outcomes. Compute and hash all deterministic pre-sampling covariates and greedy responses before any sampled answers; then compute the finite loop labels under the fixed source/horizon/twin criteria and retain every disposition. Sampling starts only after those records are sealed. Keep the soft-loop label distinct from the ordinary growing-context generation being predicted. Pin generation dtype/effective-precision scope, seed/chunk policy, sample count, token cap and first-integer rule, and retain full answer text/token records needed by that rule. Covariates may reuse the seven previously declared BPC features for continuity, but greedy correctness, correct-token probability and arithmetic answer features are gold-dependent: that is a labeled benchmark adjustment, not an answer-blind deployment diagnostic. A separately specified answer-blind model is secondary, not a replacement selected after observing results.

**Primary estimand and uncertainty.** Fix the primary to the chaotic-indicator coefficient in a declared linear projection of per-prompt fraction correct on an intercept, label and the pre-specified covariates. Use a two-sided 95% prompt-cluster bootstrap interval (10,000 draws, fixed seed, linear quantiles), retaining all samples/conditions of a prompt or arithmetic-equivalence cluster together. Record full rank, label support, every undefined replicate and the exact resulting denominator; do not silently drop failures or add prompts after seeing the coefficient. A negative interval excluding zero supports a negative adjusted association under this specified analysis. An interval including zero does not prove equality or no useful effect. The bootstrap is an approximate calibration conditional on the cohort/design, not a randomized experiment. An unconditionally shuffled label is not an exact conditional-independence test when label and covariates are associated; it need not be promoted to the new primary decision rule.

**Predictive secondary and repeated measures.** Freeze a prompt/semantic-cluster train/test split before outcomes. Fit preprocessing and both baseline/label-augmented prediction models on training data only, with fixed specification and convergence reporting. Report the paired held-out log-loss difference and a test-prompt cluster interval, explicitly conditional on fitted models if training uncertainty is not resampled. Keep model, temperature and template strata separate; if repeated conditions are included, preserve the original prompt allocation and cluster structure. No independent-row inference over repeated answers. Report covariate/common-support diagnostics and unknown/nonfinite labels without changing the cohort after seeing performance. Raw, greedy-correct, continuous-exponent and edge/tail summaries remain declared secondary/descriptive; exposed BPC/BPCS tails cannot become a newly discovered primary threshold.

**Decision and amendment discipline.** Any final freeze must fill the stated open population/resource/precision choices and the treatment of undefined inference before sampling. No budget, model launch or experiment is authorized by this outline. Preserve failed/incomplete attempts and dated changes. A future steering variant would need a separately declared fresh calibration/analysis split; even randomized steering would not by itself isolate a regime-mediated causal effect because steering has other pathways to answers. BPC/BPCS historical results remain exposed development evidence throughout.
