# Task16 independent saved-field audit — prepared, not executable

This is an independent finite field and count check of the accepted Task16 tabulation. It imports neither the tabulator nor producer analysis, and performs no model execution, fitting, statistical estimation, spectrum calculation or original pod query. All code is newly written for this saved-result check. The original source was read only for field semantics.

The exact source is `audit.py`. The prepared card is deliberately unlaunchable: Inference must supply the original reviewed plan/card, two captured scientific source files, actual terminal closure, separate supervisor/source/output authority, and all 51 original output hashes and byte counts after the original run has closed. Root reviews that concrete card and its original authority before Inference's single bounded launch. An original job failure cannot be relabelled success by this checker.

Before decoding numeric arrays, the checker authenticates those original pins, the terminal exit/timeout/failure/writer closure, actual source/plan/card association, all 51 output files, and the six accepted prospective input authorities. Inference supplies literal JSON-pointer assertions for observed supervisor closure and source/output inventory authentication; the assertions are checked against separately pinned actual reports. Those historical execution observations belong to Inference, not to this script. The original inherited archive and remote-asset limits remain explicit.

For each of 16 maps, original header/receipt metadata independently binds the selected raw path, bytes/hash, exact axes, completed prefix, layout, original run status and command. The fixed ordinal amendment is lower rows 0–95 plus top rows 96–127 for each Qwen random map. No tolerance search or interpolation is used. The additional completed lower rows 96–111 for random2/3 are retained as 4,096 nonselected observations. The original status 124 lower runs remain status 124 in the comparison. These pins and selections were accepted before outcomes.

The audit reads only the four numeric NPZ arrays and, for partial files, scalar `done`. It validates the exact recorded dtypes, shapes, duplicate-member absence, 128 MiB uncompressed archive bound, finite increasing axes and the exact done prefix. Unwritten initialized zeros are never classified. It constructs pointwise expected field values, compares every selected logical record and every allocated source record, then checks every saved summary: complete/valid/invalid/unfinished fields, period histograms, half-integer medians, strict L > 0.001 with q = 0, all five signed absolute-alpha bins, explicit exact zero and both signed nearest columns, every temperature row and alpha column, every source-prefix summary, all 4,096 overlaps and their signed differences. Literal-coordinate common-valid groups and repeated full reports are checked too. There are no new scientific gates or outcome-driven exclusions.

Every JSON field and floating arithmetic result uses exact comparison. Unlike a fitted numerical calculation, these statistics consist of integer counting, small-integer medians and the same explicit IEEE subtraction/division of saved scalar values; an arithmetic tolerance is not needed. Every nonzero discrepancy is retained in `differences.jsonl`, including tiny differences, with a failed disposition. Missing/extra fields, booleans replaced by numbers and duplicate JSON keys also fail. Excess differences beyond the output budget explicitly make the audit incomplete; no excess discrepancy is silently treated as passing. Both successful and failed attempts are preserved.

The checks retain all fields of each expected output record and summary, not merely aggregate percentages. Passing leaves are counted, while every differing field is written. `report.json` records dataset coverage, exact input/output pins, authority assertions, elapsed time and peak RSS. All original files are hashed again after the comparison. Inference independently owns the audit's actual supervisor, terminal reaping, source inventory and final closure authority.

## Tiny controls and resource basis

Twelve new synthetic controls passed in 0.003 s test time, 0.10 s external wall, 20,880 KiB peak RSS. They cover threshold equality, positive-exponent/positive-period discordance, invalid/nonfinite fields, completed partial rows, initialized unfinished zeros, overlap preservation, duplicate selected ranges, exact coordinate mismatch, every bin edge, missing exact zero, signed nearest columns, null denominators, half-integer medians, JSON/schema mutation and literal rather than nearest common coordinates. They neither import the independent producer being checked nor read target arrays. The initial source and original control logs are retained.

A separate tiny synthetic saved-read measurement checked 4,096 JSONL records / 1,232,938 bytes and 69,633 fields, including two SHA256 reads, in 0.083546 s at 20,744 KiB peak RSS with zero differences. This measurement covers parsing and exact field-check throughput only. Scaling its record count to 237,568 original selected/source rows gives about 4.85 s for that part; scaling to the original 128 MiB output ceiling gives about 9.1 s. These are estimates, not hard bounds or measurements of target archive decoding, all summary aggregation, cold storage or authority IO. The accepted original raw input size is 3,248,045 bytes. Actual 51-file bytes and exact hash/read volume must be filled from the sealed original manifest before admission. No target timing run is requested.

Proposed bound: one CPU worker plus external supervisor, nice 10, 4 GiB hard address space, 120 s absolute external deadline, 16 MiB audit output, 20 GiB startup / 16 GiB runtime available-memory floors. Fixed ceiling, no automatic extension or retry. Peak memory is constrained by the cap; finite workload is 112,640 selected rows, 124,928 allocated source rows, 116,736 completed source rows, 4,096 retained overlaps, 19 NPZ inputs and 51 original output files. The external supervisor/card must be separately concrete and reviewed before execution. This prospective checker adds no model or numerical experiment.

The final twelve controls were rerun only after adding the original terminal plan/card/wrapper association checks; both initial and final logs remain. The synthetic read measurement was made on the initial checker, whose comparison and arithmetic functions are unchanged in the final version. No original source tests were repeated.
