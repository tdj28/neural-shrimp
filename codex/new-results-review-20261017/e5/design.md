## Exact computation

The fixed development set has eight prompts and the held-out set has 24; each held-out system appears with four openers and each opener with three systems. The original 24-point temperature grid and exact stored order are retained. All four loop batches (768 cells), all 32 first-step logit vectors, all 33 sample files (development eight, held-out 24, buffered development check one), every stored gate and every saved scalar row are read. Original final-state histories are not regenerated.

The independent code determines exact suffix periods and longest periodic tails from token IDs. It recomputes all repetition fractions, histograms, onsets, strict half-repeat crossings, interpolation, censoring and recrossing flags. It checks both frozen window96/period48 and the already recorded original-card window96/period32 sensitivity. The frozen rule is applied unchanged; outcomes do not select thresholds.

Average ranks are computed independently by pairwise comparison. Correlations use centered sums. Each bootstrap call uses seed20261607, 10,000 prompt-index draws; opener/system cluster draws use sorted whole clusters. Seed resets and row order follow the original analysis. Seven bootstrap endpoint streams and one permutation stream are retained for each of the two panels, including all values, nonfinite draws, indices, linear percentile intervals and the paired partial correlation. The original two-sided permutation uses seed20261608, inclusive absolute exceedance with its literal 1e-12 comparison slack and plus-one correction; raw hit fraction, count, undefined diagnostics and a separately qualified p field are also retained. A zero hit fraction is not an exact p=0 or a calibrated p<1/10,000 claim. Undefined observed correlations do not become qualified significant results.

The matched-temperature contrast retains chaotic, periodic and irregular counts at every temperature. Only temperatures having both groups contribute, with the exact original weight nC*nP/(nC+nP). Resampling retains each prompt's label and repetition fraction together. The primary/secondary interpretations remain finite associations conditional on the fixed cohort. Separate opener and system cluster sensitivities are not a two-way-cluster or population-randomization proof.

Every source-defined loop gate is recomputed from saved fields, including the deliberate exemption of retired and supplementary periodic cells from the saved residual test. Classification/period association and the available symbolic sequence are checked separately; they are not silently turned into additional exclusions. The final native ring, 64 consecutive retirement closures and supplementary leading sequence are not saved, so their historical correctness cannot be independently reconstructed. Finite-twin exponents are saved estimates, not infinitesimal Jacobian exponents recomputed by this audit. Twin collapses, class mismatches, nonfinite states and source failures are retained.

All 32 saved float64 logit vectors independently supply the full and EOS-masked entropy curves, H(T=1), max probability and entropy inversions. The own inversion is 64 bisections on natural-log T in [-12,12], with the source 1e-8 entropy residual test, not interval arithmetic. Every discrepancy from saved H values is retained. The float32 sampling H scalar and sampled-path entropy means are inherited: their logits are not stored. No tokenizer/model replay is claimed.
