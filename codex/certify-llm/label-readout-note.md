If the paper claims that particular sequence rigorously, bind the proved phase
boxes, exact model, prefix, parameters and tokenizer bytes. For each phase box
X_i, a sufficient gate is a full-vocabulary enclosure with
`lower(p_expected(X_i)) > max_(j != expected) upper(p_j(X_i))`, using strict
outward-rounded comparisons and every one of the 151936 vocabulary entries.
This proves a unique expected argmax at the unknown exact root state in X_i.
A point enclosure at the approximate centre alone is insufficient unless a
separate rigorous variation bound covers the rest of X_i. An equivalent
strict whole-box logit comparison is valid because the common temperature is
proved positive and softmax preserves logit ordering; it may avoid unnecessary
normalizer overestimation. Neither route permits dropping vocabulary entries
or substituting a numerical top-k list.

A future observer can retain these margins during a complete primal/box
calculation, without changing the map. Its artifact should record each expected
token ID, exact phase indexing, maximum competing upper bound and witness ID,
strict margin, complete-vocabulary count, domain/map/evaluator hashes and the
pinned tokenizer hash that links IDs to displayed strings. The phase convention
is the argmax readout of F at x_i; any cyclic rotation used to print the sequence
must be explicit. A tie or unresolved margin fails the label gate while leaving
an independently successful state-orbit theorem intact.

Even certified labels describe the dominant-token readout of this fixed-prefix,
soft-feedback orbit. They do not assert that ordinary growing-context greedy or
sampled autoregressive generation follows the same text cycle. No observer code
or target run was added for this note, and no existing source snapshot or hash
was changed.
