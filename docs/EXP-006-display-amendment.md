# EXP-006 display and verification portability amendment

2026-09-11, after executable experiment freeze `ddb568e` and before rendering
the completed target results. This amendment changes only the saved-data
figure verifier. It does not change target execution, eligibility, selection,
waveform objectives, estimator definitions, bootstrap draws, or any scientific
threshold. The frozen executable experiment files remain unchanged.

The figure verifier originally required bitwise equality for every rebuilt
array and exact equality of the nested figure-condition dictionaries. Some
plotted arrays and condition fields contain recomputed arithmetic: means,
bootstrap quantiles, and `tanh` of saved states. ARM and Linux numerical
libraries can differ in their last bits even when the immutable raw input
bytes and scientific outcomes agree. No cross-machine mismatch was observed
in this amendment; this is a prospective portability correction identified
during code review.

Source hashes, saved raw hashes, generated output hashes, array field census,
array shape/dtype, integer arrays, boolean arrays, and categorical conditions
remain exact. Rebuilt floating-point and complex arrays use relative tolerance
`1e-12` and absolute tolerance `1e-14`, with matching NaNs representing the
same undefined cells. The same arithmetic tolerances apply recursively to
floating fields in figure conditions. Every eligibility flag, defined/undefined
gate, selected anchor, arm, seed, node index, and failure count remains exact.
These are the protocol's arithmetic replay tolerances, not altered dynamical
or utility decision thresholds.

`--verify` additionally requires byte-identical regenerated PDF, SVG and PNG
outputs in the same rendering environment. This remains stricter than portable
numerical `--check`. All four synthetic figure families were visually checked
outside the repository, their images regenerated byte-identically, and a
deliberately failed required trial produced the expected undefined dose and
pooled comparisons. Focused replay checks accept last-bit float changes and
matching undefined cells while rejecting a changed integer, a changed
boolean gate, a changed shape, or a material numerical discrepancy.

The utility plate was also reformatted from 11.8 by 13 inches to 11.8 by
8.8 inches so its six panels can occupy a dedicated landscape manuscript
page. Axis ticks, heatmap numbers, policy legends and pooled estimates use
nine-point text, retaining at least seven-point text at a 9.8 by 7.2 inch
placement. Both refinement columns use common dose and benefit axis limits.
The displayed means, intervals, all eleven arms and fixed selection rules
are unchanged. This layout adjustment responds to manuscript print-size
readability, not to any target effect.
The other three plates also use nine-point ticks, legends and explanatory
labels for landscape placement. No numerical arrays were altered for layout.

After inspecting the completed continuation data, the linear multiplier axes
were found to compress the scientifically relevant +1/-1 region because
accepted unstable multipliers reach approximately 155 in magnitude. The
multiplier axes now use a labeled symmetric-log scale, linear within ±2.
All nodes, signed values, crossing markers and failures remain displayed;
neither selected branches nor numerical arrays changed. This exposes both
the stability thresholds and the distant unstable segments on the same axes.
