# Curry and Yorke reference check, 8 October 2026 UTC

The current manuscript's use of this source for one possible circle-breakdown
route is supported by the publisher's two-page preview, printed pages48–49.
Both pages were read as extracted text and inspected visually. The abstract
and introduction describe numerical examples in plane maps: an attracting
invariant curve becomes distorted and subsequently ceases to be a curve.
This is not a universal theorem that every NS bifurcation proceeds to chaos,
or evidence that our learning maps follow the same global transition.
