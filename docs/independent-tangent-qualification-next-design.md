# Post-interpretation decision: independently qualify the full tangent response

17 September 2026. This is a new decision note after EXP-015, not an amendment to its frozen plan or an executable authorization. The original interpretation report, its 11,145 saved-result checks and the prose erratum remain immutable. This note proposes no new target computation now.

The next most decisive bounded step is independent full tangent and clock qualification at **all sixteen original setting/phase contexts**. EXP-015 established an interpretable partition of its inherited propagators. It did not independently establish the accuracy of every transverse column. An exact algebraic partition and agreement with the old full-linear routine reuse the same numerical object; transport of the flow vector tests only one direction. Independent alternate arithmetic also retains strict discrepancies. These limits matter before making stronger claims from the signed gain patterns.

## Concrete proposed successor

Keep both original settings and phase indices 0–7, including every context implicated by EXP-014, its refinement or EXP-015. Bind the original weights, saved initial states, epochs, periods, adjoints, directions, pulse additions, clock times, orientation, weights and noise levels. Do not reshoot an orbit, retune its period, alter a decoder or select a favorable phase. All sixteen contexts are required; neither the previously reported example nor the thirteen failed EXP-015 cells determines inclusion.

Use two prospectively fixed, numerically distinct solvers for the **continuous unperturbed state plus all nine entries of its tangent matrix**, starting with the exact old state and the identity matrix and running directly to eight original periods. This gives **32 bounded integrations**, not finite-pulse trials. A concrete candidate pair is DOP853 and Radau, both with rtol=1e-13, atol=1e-15 and max_step=.00625. The executable implementation and exact settings still require synthetic review, a measured historical resource justification and a private source/plan freeze before any such outcome. Their agreement is a numerical consistency test, not a rigorous error enclosure.

Use independent vectorized state/Jacobian evaluation for this successor, cross-checked algebraically against the original equations on synthetic inputs. Preserve every adaptive accepted step, final status and requested output. Evaluate all four original 32-point clock windows, every original one-period knot and all integer-period endpoints without altering their times. The unchanged clocks remain authoritative even if a newly integrated reference drifts relative to the old periodic template.

Separate three comparisons, preserving all components rather than combining them into a favorable scalar:

1. **Independent continuous-solver agreement:** unperturbed state, activation, complete tangent matrices and clock readout operators between the two new methods. This tests integration consistency without imposing periodic stitching.
2. **Saved versus independent response:** compare each new direct eight-cycle tangent with the old `Phi(s) M^k` at every saved sample. Record both differences in the base reference and differences in the tangent. Compare activation response once using the original template derivative and once using the derivative along each independent reference, so reference drift is visible rather than silently absorbed.
3. **Periodic composition within each new method:** compare its direct solution against composition of its own first-period fundamental matrix. Because the saved starting point only closes numerically, exact periodic coefficients are an assumption. This diagnostic can distinguish a repeated-period/template discrepancy from disagreement between integrators; it does not repair the original reference.

Retain raw elementwise, absolute and relative matrix differences. Use the existing state/activation/readout relevance scales, frozen before new outcomes, to add an interpretable full-column check. At each sampled time, a difference operator E in state space obeys `max_i |(E delta)_i| <= r max_i ||E[i,:]||_2` for any Euclidean displacement with norm at most r. With r=.01, compare this bound to the inherited 1e-6 state scale. Apply the same row-norm rule to the activation-response operator and the inherited 1e-7 scale. For each entire 32-point clock, use `.01 ||Delta L||_2 / (1e-4 ||w||_2) <= .01` for the difference in the frozen signed readout row L. These are prospective numerical relevance criteria over local linear inputs, not acceptable task-loss thresholds or validated finite-amplitude error bounds. Retain explicit signed comparisons for all six original realized pulses at each of the 192 direction/window cells as well.

Keep the original strict arithmetic lane separate and unchanged. Do not replace its 1e-14/1e-12 tolerances with physical relevance tolerances. Report results by solver pair, context, horizon and operator component, with every failed prerequisite and incomplete job. No original setting mean, success claim or retrospective requalification follows from this diagnostic. If independent methods agree but both disagree with inherited composition, study the reference/periodic-extension assumption next. If the methods disagree, preserve that numerical limit before drawing new mechanism conclusions. If all comparisons pass, the local transverse interpretation has stronger independent support; it still does not establish geometry utility or network capacity.

A suitable local resource envelope to evaluate during executable review is four owned CPU workers, one numerical thread each, no GPU or paid resource, an exclusive external attempt, a 600-second per-job and 1,800-second producer ceiling, and 120 seconds for sealing failure evidence. Those ceilings are proposals, not measured runtime claims. Apply the current memory-headroom and owned-process policies; measure actual reference, integration, interpolation, scoring and verification costs separately where feasible. A timeout remains a retained failed job, not a reason to adapt the solver after observing target responses.

## Why this takes priority over the alternatives

The earlier interpretation report proposed reusing 624 saved small-pulse/sham trajectories. That would add an explicit complete signed, odd/even and dose-dependent nonlinear-remainder inventory. It could answer whether errors scale as a linear approximation predicts and whether even components explain deviations. But EXP-014 already scored phase-only and full-linear predictions at these clocks, and the refinement already examined selected dose/sign pairs. Merely repeating those comparisons would add little independent evidence and would leave the shared tangent-solution assumption untouched. Such a saved-data extension is secondary and should identify genuinely new residual endpoints before another freeze.

A trained-network transfer is a separate scientific question. It would require an actual trained checkpoint, independent seed/task evaluation and controls for forcing, readout and noise. It cannot resolve whether this inherited three-neuron tangent calculation is accurate. The present results are consistent with ordinary oscillator phase and transverse response; they do not establish a shrimp-specific mechanism.

This recommendation changes neither EXP-014's failed setting qualification nor EXP-015's original 191 algebraic / 179 ideal-neutral flags. The published noisy-readout probabilities remain analytic consequences of assumed Gaussian measurement noise, not results from sampled noisy trials.
