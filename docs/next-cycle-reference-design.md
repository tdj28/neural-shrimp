# Next study: comparable cycle references before more memory trials

**Human-friendly TLDR:** We now know that the near-edge cycle can retain an input that a linear observer misses. We still need to determine how much of that behavior follows from ordinary contraction and how well inputs become visible at the output. The next study first checks whether comparable cycles exist. It can identify suitable controls—or show that our proposed controls do not match—before another large memory experiment.

## What this can establish

Matching the full A/B Gram triple and Gaussian noise already fixes the reference mixture probability. A geometry label cannot add predictive information about that identical mathematical quantity. A residual against actual finite responses would instead measure model mismatch. Contraction and observability may also mediate geometry's association with memory; conditioning on them asks about an additional predictive contribution, not whether periodic organization matters at all.

This pilot can establish common support and numerical feasibility. It cannot establish a geometry advantage, complete shrimp boundaries, basin size or trained-network transfer. A useful negative outcome is that the two paths supply no suitable matched controls. Unmatched or failed cases must not trigger an expanding search for favorable evidence.

If feasible, a separately frozen identity-only two-write assay could evaluate all six cycles and eight phases, retaining both pulse signs and zero-write controls: 864 native-resolution traces plus 108 independent-method traces, **972 total**. That later census is a proposal, not a current launch. No nonlinear decoder expansion or flexible geometry model is implied.

If ordinary observable transport predicts the behavior closely, parameter robustness may be the better geometry question: does independently measured multidirectional window organization predict preservation of matched memory under a fixed distribution of parameter changes? That requires a later boundary and perturbation study. These gamma paths alone cannot supply its labels.
