## Decision: accept the behavioral experiment with modifications

The [complete advisory response](2026-09-17-pro-response.md) is preserved
byte-for-byte. Pro saw the compact synthesis, not the raw data. Its advice and
the local agent review share potential model-family blind spots; neither is
independent scientific validation. The [separate local critique](2026-09-17-two-write-independent-adjudication.md)
identified additional construct, census and numerical requirements.

| ID | Finding and disposition | Evidence, plan change and rationale |
|---|---|---|
| R01 | **accepted_modified:** prioritize two-write memory under interference | EXP-014/015 suggest persistent transverse readout but do not test competing inputs. Use a fixed-observer first-bit task with the second bit unknown, no-second-write controls and state-component interventions. |
| R02 | **accept:** put numerical qualification inside the behavioral study | The old failures remain. Every new history needs numerical checks; a saturated accuracy score cannot substitute for state, activation and signed-margin agreement. The previous 32-job tangent design is retained as a conditional diagnostic, not the current main question. |
| R03 | **accepted_modified:** covariance-weighted linear decoder | This decoder is not Bayes-optimal for a binary mixture. Name the endpoint accuracy of the prespecified linear observer. A one-mode memory can encode four distinguishable amplitudes while a zero-threshold linear decoder loses the first bit. Include that synthetic counterexample; no claim of total capacity or information erasure. |
| R04 | **accepted_modified:** phase-conditioned readout and reference subtraction | Declare known initial phase and external clock for all comparators. Subtract only the presealed zero-write reference under the same reset schedule. Never subtract a reference conditioned on the hidden second-bit sign. Freeze the same identity-arm observer across interference and intervention contrasts. |
| R05 | **accepted_modified:** timing-only and transverse-only retention | Evaluate flow and adjoint at the declared nominal intervention time. These are oblique local projections, not exact isochron resets or norm-preserving biological operations. Retain realized replacement, normalization, idempotence, leakage, amplification and no-write/reset-only controls. |
| R06 | **accepted_modified:** interpret component removal | Reduced performance with the identity-arm observer shows a contribution to that observer. It need not mean all information was erased. A separately presealed arm-specific linear observer may diagnose reformatting; it cannot replace the primary endpoint. |
| R07 | **accepted_modified:** freeze predictions and chronology | Seal phase-specific reference, first/second-write linear responses, decoder and comparator before finite-pulse outcomes. Reach T exactly; first evolve, then replace the deviation, then add the second write. The first linear response passes through the intervention before the second response is added. |
| R08 | **accepted_modified:** close the task census | Pro's 576 is only the held-out nonzero-first-write subset. The complete 2 settings × 24 phases × 3 first signs × 3 second signs × 3 interventions contains 1,296 histories, including 432 development and 864 held out. Numerical repeats, references and independent panels are additional jobs. |
| R09 | **accepted_modified:** independent numerical panel | Twelve selected checks alone do not qualify all reset histories. Require complete primary-resolution comparison and a prospectively fixed independent-method panel covering both settings, development/held-out status and all interventions/sign controls; retain all failures and failure bounds. |
| R10 | **accepted_modified:** simple dynamical baselines and uncertainty | Include the full-linear scheduled response and an explicitly matched one-mode model, with identical noise/information access. Phase blocks, not signs/windows/solvers, are the units for a descriptive paired interval conditional on these two selected cycles. No geometry-causal or trained-network inference. |
| R11 | **reject:** adopt an unsupported five-percentage-point utility threshold | No task has supplied that utility margin. Report effect magnitude and uncertainty; do not call a result useful merely because it clears an arbitrary threshold. Choose any future continuation criterion prospectively with a stated decision rationale. |
| R12 | **accepted_modified:** local resource plan | Prior measured CPU performance is the planning evidence. Pro's 15–120 CPU-hour estimate and 8–12 workers are unmeasured suggestions. Begin with at most four owned workers and one numerical thread each, measure the fixed development workload, retain RAM headroom and owned PIDs. EXP-012 does not qualify GPU acceleration for this pipeline. |

| R14 | **defer:** finite-pulse sign reversal and nonlinear mixing | These are separate follow-ups with their own frozen questions and dose/numerical contracts. Do not launch all proposed directions or treat the linear interference study as nonlinear computation. |
