# Independent adjudication of the two-write recommendation

17 September 2026. Saved advisory response reviewed without simulations, new fits, target calculations or paid calls. Review source: `/data2/neural-shrimp-data/consults/2026-09-17-strategy/attempt-001/review.md`, 21039 bytes, SHA256 `ff81ca3e906f53711a549fadcf01fc9896a73d69920ecd89a6c5051d723f65e6`. This note is a protocol critique, not independent validation of the consultant or an executable freeze.

**TLDR — What would we learn about neural behavior in shrimp regimes?** The useful next question is whether the lingering response in the selected near-edge neural rhythm helps a fixed observer recover an earlier input after another input arrives. A positive result could demonstrate usable short-term signal retention in these two cycles; a negative result could show that persistence mostly causes interference for that observer. Neither result would establish special shrimp computation or transfer to trained networks. The recommendation is worth pursuing after the changes below.

## Disposition: accept the question; revise the experiment before execution

The proposal moves beyond describing one isolated response and creates a falsifiable behavioral task. Keep the complete full-linear explanation as a strong comparator, both no-second-write and interfering-write conditions, signed continuous readouts alongside analytic accuracy, and an explicit local state intervention. Embedding independent numerical qualification into this task is reasonable. It must not become a reason to waive the original failures or ignore trajectory disagreement merely because saturated accuracy is unchanged.

### 1. Limit the decoder claim and specify its information

**Required change.** The covariance rule `h proportional to (sigma^2 I + B B^T)^-1 A` is a linear covariance/SNR rule. It is not the exact Bayes classifier for the binary Gaussian mixture generated by an unknown second bit, nor is it necessarily the accuracy-optimal linear threshold. Name the primary outcome **accuracy of the prespecified linear observer**, not total recoverable information or maximum memory capacity.

A one-mode memory can produce four distinct amplitudes `+/-a +/-b`. When the second-write contribution dominates, a zero-threshold linear observer can approach chance for the first bit even while a nonlinear classifier distinguishes all four low-noise levels. Therefore linear-observer failure cannot establish that the first bit was erased. A separately frozen exact-mixture oracle is a useful optional diagnostic, with its numerical integration and full-linear versus finite-trajectory scope declared in advance. Do not use oracle performance to replace an unfavorable primary endpoint.

Declare whether the observer knows the initial phase. A phase-conditioned h uses that information; all baselines must receive it. Freeze orientation, normalization, any intercept, and the same interference-derived h for the no-second-write and reset comparisons. The subtracted reference must be a presealed zero-write baseline under the stated reset schedule, never a baseline conditioned on the unknown second-bit sign. Otherwise the nuisance write is supplied to the decoder through subtraction.

### 2. Interpret component removal as a local state intervention

**Required change.** Evaluate f and Z at the nominal intervention-time reference state, with an explicit clock/epoch convention. Approximate period closure does not justify silently treating t=0 and T as identical. Use the original unrepaired oblique Q and P; preserve normalization error, nonidempotence and realized floating-point replacement. Qd and Pd need not be smaller than d. Record the replacement norm, resulting displacement norm, phase leakage and numerical sensitivity for every history.

The identity arm should execute the same save/replacement pipeline, and the zero-first-write conditions should include every second-write/reset combination. Retain reset-only/no-write baselines. These operations have privileged access to the full simulated state and remove local linear components; they are not biological mechanisms, practical controllers or exact nonlinear isochron resets.

A decrease under the fixed identity-arm decoder demonstrates a contribution to that **fixed observer**. It does not prove all decodable information was removed; the reset could reformat the signal. Either freeze an arm-specific, reference-only linear decoder as a secondary diagnostic or keep this narrower causal claim. Do not learn such decoders from held-out bit trajectories.

### 3. Freeze predictions, exact event chronology and a matched baseline

**Required change.** Seal all new phase-specific reference inputs, A/B predictions, decoder parameters and complete linear-control outcomes before their finite-pulse trajectories. For a linear intervention H at T, the first-write response passes through H before later propagation; the second write is added afterward. A full-linear baseline must compose that actual schedule, not add two isolated identity responses. Retain exact requested and realized pulses.

Specify T-minus, replacement, and T-plus second-write ordering and how each solver reaches the exact event time. Do not round T to its nearest native timestep. Keep all observation clocks and noise assumptions fixed. Count new reference/variational qualification for all 48 setting/phase contexts, rather than assuming the old sixteen contexts cover newly drawn phases.

The primary equal-native-norm experiment measures performance at equal input effort. A development-frozen immediate-detectability-matched analysis can help separate input/readout gain from persistence, but its unequal physical pulses must be reported and it cannot replace the primary. A one-mode baseline needs an explicit matching and fitting recipe, observation-noise budget and the same information access. Compare its prespecified linear observer with the network's corresponding observer.

### 4. Close the complete census and numerical contract

**Required change.** The quoted 576 is only the held-out nonzero-first-write matrix. A straightforward closed census is first-write sign in {-1,0,+1} times second-write sign in {-1,0,+1} times three interventions: 27 scheduled histories per setting/phase. Across two settings and 8 development plus 16 held-out phases, that is **1,296 histories** (432 development, 864 held out), before solver repeats, reference jobs or additional controls. Windows, signs and reset arms are repeated conditions, not extra independent units.

For illustration, two complete primary resolutions would require 2,592 trajectory solves. An independent solver panel containing all 27 histories at the first frozen development and held-out phase for each setting would add 108, totaling 2,700 pulse/reset solves. This is a count-complete design option, not the final selected resolution/panel. Synthetic observation controls need no neural integration; immediate detectability can share early saved samples if the window is prospectively specified. Any prefix or identical-history reuse must be explicit in the task and cost ledger.

Twelve selectively checked cases do not qualify every nonlinear reset history. Freeze complete primary-resolution checks and a deterministic independent panel before outcomes; include all reset and absence controls. Keep state, activation and continuous noise-standardized score comparisons as well as accuracy. Oblique reset amplification can move an otherwise small write beyond the previously tested small-pulse regime. Failed numerical or intervention cells remain visible; they are not evidence of rich dynamics. If partial-cohort accuracy bounds are allowed, define their all-phase denominator and worst/best-case arithmetic prospectively, without requalifying any older study.

### 5. Do not invent practical significance or inflate the sampling scope

**Required change.** The proposed five-percentage-point expansion threshold and interval target have no supplied application rationale. Do not treat them as established useful-performance thresholds. Prefer an exploratory complete paired effect/error/cost report with prospective decision branches; add a practical margin only when a task requirement justifies it.

Freeze the phase distribution and paired sampling seed, development/held-out roles and all analysis choices. Phase variation can support conclusions about that declared phase distribution at the two fixed cycles. It does not provide independent replication across neural systems or a causal shrimp-geometry contrast. Bootstrap phases, not bit histories/windows. A failure of the chosen linear observer does not reject memory in general, and full-linear prediction of a behavioral advantage would be informative evidence for a generic mechanism rather than a failed task.

### 6. Replace unmeasured resource estimates with local evidence

**Reject as a run plan.** The advisory 15–120 CPU-hour estimate and 8–12-worker suggestion are not grounded in this implementation. The recent 425-trace refinement completed in about 178 wall seconds with four workers; that historical measurement does not predict this new workload exactly, but it makes the supplied estimate unsuitable as a measured budget. Keep the established four-worker cap and one numerical thread per worker. Account for all reference, decoder, development, held-out, independent-solver, failed and verification work. Any target-bearing development benchmark needs its own frozen stage; synthetic timing is available before that freeze. No additional paid resource is implied.

## Recommended next decision

Proceed to a bounded executable design of the two-write **prespecified linear-readout** task with complete controls and prospective numerical qualification. Incorporate the independent full-tangent check where it determines predictions and their uncertainty, rather than running a disconnected accuracy-only comparison. Keep the already drafted standalone tangent study as a documented alternative if the new behavioral design cannot qualify its references or reset operations.

Do not run the pilot from this advisory sketch. Finish the endpoint, baseline, clock/reset semantics, complete census, failure treatment, resource evidence and independent local review, then privately freeze the exact code and plan. The outcome could tell us whether persistent departures from a repeating neural rhythm help retain a previous write under interference. It would still leave boundary organization, geometry's incremental value and trained-network transfer open.
