# EXP-014 refinement design amendment, 17 September 2026

This amendment precedes every new EXP-014 refinement trajectory. The selection
is outcome-aware: it uses EXP-014 recovery attempt-002's already saved failures.
No new refinement outcome informed this change.

The first proposal selected the18 unique signed strong-pulse cases failing any
original full-trace comparison, the36 matching smaller-dose signed cases and
seven affected-phase shams:61 physical cases,305 new integrations and1,708
comparisons across eight old/new methods. That proposal is superseded before
execution. It was unsuitable for a complete set of same-method binary readouts
because some opposite signs were absent.

The accepted design includes both signs in each of the13 affected
(setting,phase,direction) contexts at all three original doses. This gives78
pulses plus the same seven shams,85 cases,425 new integrations and2,380
all-method pair comparisons. Both signs use the same numerical method in every
one of3,744 analytic Gaussian-noise balanced-accuracy diagnostic cells.

This broadening completes matched binary contexts without selecting new cases
from new refinement outcomes. It does not qualify either original setting,
change original thresholds or generate an original-cohort mean. The large
potential/activation disagreements and unsaturated signed clock scores remain
central; nearly saturated balanced accuracy cannot substitute for waveform
agreement. The independent metadata derivation retains both proposal versions
outside the repository under
`/data2/neural-shrimp-data/checkpoints/phase-memory-refinement-review-20260917/`.
