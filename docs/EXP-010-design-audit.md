14 September 2026. Pre-execution review of the complete original short-preview
qualification. No EXP-010 target integration was run for this review. The
protocol, code, tests and complete input manifest must be privately pushed
before execution. This is numerical development following observed EXP-008/009

## Design scope

The reviewed census includes all 3,456 original previews: 24 physical origins,
two phases, four radii and eighteen candidate entries, forming 192 complete
contexts. Original policy choices identify a diagnostic subset of 220 distinct
entries and 384 policy assignments. The independent panel uses only old
preview scores: maximum and lower median in each of eight 432-entry strata,
giving sixteen distinct sentinels. No new outcome selects the panel.

Each original initial state, realized direction/destination, reference orbit,
phase epoch and sample time remains bound. Two smaller native steps supply
6,912 traces; two DOP853 settings on the fixed sixteen-case panel supply 32.
The independent reviewer reconstructed these counts and replayed the original
sentinels' saved metric trees exactly, without new integration.

The endpoint remains the original 75-unit preview RMSE. Full candidate ranks,
minimum choices, top-four membership, best/second and fourth/fifth gaps, and
empirical score changes are retained. A change in candidate identity is
distinct from a material change in minimum error. Observed numerical
differences are not rigorous exact-solution bounds or task-quality margins.
This packet fits no learner and establishes no 300-unit benefit.

## Resource decision

Use four local CPU workers with one BLAS/OpenMP thread each, a 60-second
per-trace ceiling and a 3,600-second target-execution ceiling. Reuse the
unchanged EXP-009 owned-worker scheduler, parent-death handling, interruption
cleanup and compiler timeout logic. No GPU or paid resource is needed.

EXP-009 measured 113.06 seconds through its receipt, excluding saved-array
verification, for a larger native step workload. This is evidence that the
local server can handle the bounded qualification; it is not a timing result
for EXP-010. At 21:49 UTC the server had about 68 GiB available RAM, 3.4 TiB
free on the external data volume and load average 11.47 across 32 logical
CPUs. A subsequent GPU query reported 13,258 MiB free with other GPU activity.
Resource availability is shared and will be checked again at launch.

All new raw evidence goes to the exclusive external attempt under
`/data2/neural-shrimp-data/raw/EXP-010/`. Failures and incomplete attempts are
retained. Source/plan bytes and the exact live private remote head must match
before execution. The original EXP-008 failed gate and EXP-009 evidence stay
unchanged. A review PR remains pending GitHub API authentication; this branch
does not merge or bypass the original release qualification.
